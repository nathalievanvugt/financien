# Mijn financiën

Een app voor je eigen financiën, in één bestand (`index.html`).

- Alles wat je invult blijft op je eigen apparaat, in de browser. Er gaat niets naar deze website of naar iemand anders.
- Op een iPhone of iPad: open de link in Safari, kies deelknop › **Zet op beginscherm** en gebruik de app via dat icoon.
- Een nieuwe versie komt op dezelfde link. Sluit de app af en open hem opnieuw; je gegevens blijven staan.
